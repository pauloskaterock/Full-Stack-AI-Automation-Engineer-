# 🚀 Plano de Estudos: Potencializando Estudos e Carreira com IA & n8n

> **Objetivo**: Dominar o uso prático de Inteligência Artificial — transitando de Chatbots a Agentes Autônomos integrados a fluxos de automação no n8n —, potencializando a produtividade de estudos e acelerando o posicionamento de carreira na tecnologia.

---

## 📌 Visão Geral do Bootcamp

Este plano foi desenhado para estruturar 4 semanas intensivas de aprendizado prático e aplicado. A jornada vai desde a base de engenharia de prompts e copilotos até a criação de automações avançadas e agentes inteligentes.

## 🎯 Pilares Semanais

| Semana | Tema Central | Principais Ferramentas / Tecnologias | Entrega Prática |
| :---: | :--- | :--- | :--- |
| **01** | **Fundamentos de IA & Chatbots** | ChatGPT, Claude, Gemini, Prompt Engineering | Tutor Pessoal de Estudos com System Prompt customizado |
| **02** | **Copilotos & Produtividade no Código** | GitHub Copilot, VS Code, ferramentas inline | Script/código refatorado, testado e documentado com IA |
| **03** | **Automação de Processos com n8n & IA** | n8n (Self-hosted/Cloud), Webhooks, AI Agent Nodes | Workflow n8n automatizado integrando LLM com ferramentas externas |
| **04** | **Projeto Final Integrador & Carreira** | n8n, APIs externas, Git/GitHub, LinkedIn | Projeto completo publicado no GitHub com documentação e post de case |

---

## 🧠 Metodologia de Estudo Recomendada

1. **Aprender Fazendo (Hands-on)**: Não fique apenas na teoria; teste cada comando, prompt e nó na prática imediatamente.
2. **Técnica Feynman**: Explique os conceitos aprendidos com suas próprias palavras no arquivo de anotações semanais.
3. **Construa em Público (Build in Public)**: Documente sua jornada, publique seus fluxos no GitHub e compartilhe seus insights profissionais no LinkedIn.
